# LifeLink — Blood Donation Application

**Connecting Lives Through Blood**

LifeLink is a mobile application prototype designed to connect **blood donors, patients, and hospitals** through a single digital platform. The project focuses on improving coordination, accessibility, and communication throughout the blood donation process.

## About the Project

Blood donation is an essential healthcare service, but challenges such as blood shortages, limited public awareness, and poor coordination between donors and healthcare organizations can make blood availability difficult.

LifeLink was designed as a user-friendly digital solution to help address these challenges by bringing different stakeholders together in one platform.

## Main Features

* Blood request management
* Donor notifications
* Donation history tracking
* Patient blood requests
* Donor dashboard
* Patient dashboard
* Hospital dashboard
* Admin dashboard
* Simple and accessible navigation

## User Roles

The application includes different interfaces for:

* **Donors** — manage donation-related activities and receive notifications.
* **Patients** — submit and track blood requests.
* **Hospitals** — manage blood-related requests and coordinate with users.
* **Administrators** — manage and oversee the platform.
